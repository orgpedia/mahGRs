| सेवा संकल्प अभियानादरम्यान उक्त उपक्रम प्रधानमंत्री ग्रामसडक योजनेंतर्गत असलेल्या |
| संस्थात्मक, कंत्राटी, गुणवत्ता नियंत्रण आणि देखभाल यंत्रणांच्या माध्यमातून, विद्यमान प्रधानमंत्री ग्राम |
| सडक योजना (PMGSY) अंतर्गत मार्गदर्शक तत्तवे, तांत्रिक विनिदेश, करारातील तरतुदी तसेच देखभाल |
| व्यवस्थेच्या अनुषंगानेच राबविण्यात येतील याबाबत दक्षता घ्यावी. |
| १२. सदर प्रधानमंत्री ग्रामसडक योजनेंतर्गत कार्यक्रमांचे आयोजन करण्यासाठी राज्यासाठी मुख्य |
| अभियंता, प्रमंग्रासयो, महाराष्ट्र ग्रामीण रस्ते विकास संस्था, पुणे यांना नोडल अधिकारी म्हणून नियुक्त |
| करण्यात येत आहे. नोडल अधिकारी यांनी सेवा संकल्प अभियानाच्या अनुषंगाने नियुक्त करण्यात |
| आलेल्या नोडल अधिकारी यांचे नाव, संपर्क क्रमांक इ. तपशील तसेच निश्चित करण्यात आलेली उदिष्ट्टे/ |
| निवडण्यात आलेले रस्ते यांची आगाऊ माहिती केंद्र शासनास तसेच राज्य शासनास सदर उपक्रम सुरु |
| होण्यापुर्वी कळवावी. |
| नियुक्त केलेल्या नोडल अधिकाऱ्यांनी राबविण्यात आलेल्या उपक्रमांचा संक्षिप्त अहवाल तयार करावा. |
| या अहवालामध्ये पुढील बाबींचा समावेश असावा: |
|  राबविण्यात आलेल्या उपक्रमांची माहिती; |
|  समाविष्ट्ट करण्यात आलेल्या रस्त्यांची/ठिकाणांची संख्या; |
|  दुरुस्त करण्यात आलेल्या प्रमुख त्रुटी/उणिवा; |
|  समुदायाचा सहभाग; |
|  उल्लेखनीय परिणाम; |
|  संबंधित छायाचित्रे; आणि |
|  यशोगाथा. |
| १३. सेवा संकल्प अभियान या कालावधीत प्रधानमंत्री ग्रामसडक योजनेंतर्गत केलेल्या कामाचे व्हिडिओ |
| चित्रीकरण,रिल्स व फोटो यांचे संकलन करून सदर माहिती संबधित नोडल अधिकारी यांनी केंद्रीय |
| ग्रामीण विकास मंत्रालयास तसेच शासनास उपलब्ध करून द्यावी. |
| १४. सेवा संकल्प अभियानांतर्गत शासनाकडून कोणताही निधी स्वतंत्रपणे उपलब्ध करून दिला जाणार |
| नाही. |
